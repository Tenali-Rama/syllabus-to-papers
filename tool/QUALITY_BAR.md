# QUALITY BAR — Hard Standards for Question Quality

Every generated paper must satisfy all 12 criteria. The reviewer checks each as PASS/FAIL with an example quote; any FAIL on criteria 1–6 = automatic rejection regardless of score. Criteria are written to be grader-adjudicable (two graders must agree).

1. **Realistic magnitudes.** Numerical data must look like real data for the stated setting (daily-return variances ~10⁻⁴, ω ~10⁻⁶; sample sizes and coefficient sizes plausible for the design). Units (decimal vs % returns, quarterly vs annual) must be stated.

2. **Misconception-based distractors.** Every MCQ wrong option must be a plausible error a real student makes (a confusion with a neighboring concept), never filler. Two graders must agree each distractor is "someone would pick that."

3. **Single defensible key per MCQ.** Given only stem and options, two graders must pick the same answer. If two options are partially true, the stem must contain the discriminator.

4. **Computable, internally consistent numericals.** Unique answer from the given data alone; key arithmetic reproduces exactly at the stated precision.

5. **Worked lines in keys.** Each numerical key shows the substituted formula and at least one intermediate value — not just the final number. Each MCQ key carries a one-line justification of why the key is right (and ideally why the top distractor is wrong).

6. **Discriminating key content.** Conceptual keys state the specific mechanism ("differencing induces MA(1) in the errors"), never a paraphrase of the question or "explain appropriately."

7. **Understanding over plugging.** At least half of each paper's marks attach to stems demanding a reason, a method choice, or an interpretation — classifiable per question as compute-only vs interpret/justify.

8. **Verb matches level and marks.** State/identify ≤ 2 marks; explain/derive/compare 3–5; evaluate/justify 8–10. Two-part comparisons may not be compressed into 2 marks.

9. **Long answers specify answer structure.** 8–10 mark questions enumerate the dimensions to address, and the key maps marks to those dimensions explicitly.

10. **Self-containment.** Every numerical stem supplies all constants, critical values, and conventions needed to solve it without the syllabus or memory.

11. **Realistic framing.** Variables have names, units, and context; teaching-sized datasets may be used only if labelled illustrative.

12. **Proportional, explicit mark splits.** Key splits equal stem splits and are defensible against task difficulty (no 3 marks for two trivial computations alongside 3 marks for a multi-step derivation).

## Grading the bar
- Criteria 1–6: hard gate — any FAIL rejects the run.
- Criteria 7–12: each FAIL costs 1 point off Question Quality (per the reviewer rubric's /10), with the specific question cited.
